Five portals, one platform

Each role gets a workflow shaped for what they actually do.

Recruiter Pipeline, search, templates, parser.

Kanban with drag-and-drop status moves, candidate search with tag filters, reusable email templates with merge fields, drag-drop resume parsing, recycle bin for restorable deletes.

Open recruiter → Contractor Submit timesheet. Submit invoice.

Direct-engagement contractors log weekly hours, submit invoices, track approval, and pull payment status — without emailing PDFs to a recruiter.

Open contractor → Client Approve submissions. Review documents.

Hiring-manager-facing view of submitted candidates, signed documents, and pending approvals. One-click approve / reject with an audit trail.

Open client → Candidate Timeline, profile, quick actions.

Application history surfaced as a timeline, profile editor, and quick links into open jobs and timesheet (when the candidate is also a contractor).

Open candidate → Interviews Schedule, run, record.

Calendar provider abstraction (Google / Microsoft / Zoom) with meeting-link generation, interviewer availability windows, and self-booking slot picker.

Open interviews → Admin Audit review, RBAC matrix.

Append-only audit log queryable per actor + entity + action. Granular role / permission matrix for recruiter, HR, payroll, interviewer. SOC 2 evidence is one click away.

What's in the box

Recruiting ops

  • Candidate pipeline with drag-drop status moves
  • Bulk tag + status updates with search filter presets
  • Reusable email templates with merge fields + live preview
  • Resume parser with editable extracted fields
  • Activity timeline + recruiter comments + audit join

Time & money

  • Weekly timesheet submission with hour categories
  • Contractor invoice submission + client approval state machine
  • Pay-rate rules + QuickBooks handoff CSV
  • Stripe subscription model for tenant-level seats
  • Billing summary with trial-day countdown

Identity & trust

  • Auth0 JWT with role-based access policies
  • Multi-factor authentication ready for production
  • Sign-out-everywhere + suspicious-login feed
  • Append-only audit log on every mutation
  • 30-day soft-delete recovery window

Integrations

  • Public job-board feed (Indeed XML)

  • E-signature workflow (DocuSeal provider boundary)

AI assistance

Compliance & ops
